# Резонанс — утверждённый пакет юнитов
2026-10-27. Автор утвердил показанные визуалы с чистыми светлыми панелями для всех десяти актуальных юнитов. [Единая галерея](gallery.html) · [Общий документ](../../PROJECT.html#visuals) · [Дизайн](../../DESIGN.md#art).
## Единый стандарт
Крупные светло-серые сатиновые панели, графитовые механизмы, небольшие бирюзовые индикаторы. Свежесобранное состояние без ржавчины, грязи и сколов; микротрещины на исходных пробах не являются целевым материалом.
У каждого юнита сначала основной утверждённый визуал, затем модельный лист: FRONT / SIDE / REAR, TOP / THREE-QUARTER. Голем и Сеятель имеют отдельный лист раскрытого состояния. Листы — референсы для моделирования; точное совпадение размеров и шарниров проверяется в 3D. Основной визуал задаёт характер и пропорции при неоднозначности сгенерированных проекций. Все нейтральные виды показывают один и тот же объект; динамика и боеприпасы — отдельно.

## Происхождение и промпты
Основные визуалы — точные копии утверждённой пробы resonance-clean-panel-experiment; Игломёт взят из приложенного автором эталона. Их названия STYLE EXPERIMENT сохранены как часть исходных изображений; актуальный статус определяется этим реестром и DESIGN.md.
Модельные листы созданы встроенным image_gen: один вызов на каждый лист, входы — новый основной визуал и, где необходимо, прежний модельный референс для скрытой геометрии. Точные окончательные промпты сохранены в *.prompt.md рядом с каждым листом. Исходные промпты основных визуалов — в [папке первой пробы](../resonance-clean-panel-experiment/README.md); промпт очистки Игломёта — [в его эксперименте](../needler-style-experiment/02-c-factory-new.prompt.md).
Новые механики, посадка Сеятеля для стрельбы, числовой баланс и параметры боеприпасов этим пакетом не утверждаются. Облако и Прыгун остаются вне текущего состава.

## Проверка листов
Все 12 листов просмотрены. У Взломщика отдельно исправлен профиль антенны; у носителя гранат — закрытая задняя панель вместо ошибочного повторения переднего канала. Нейтральные английские подписи ANTENNA ROVER и TRACKED CARRIER на этих двух листах описывают конструкцию, не переименовывают юниты. Точные промпты последующих правок добавлены в соответствующие *.prompt.md.
Листы не задают точные размеры: небольшие расхождения перспективы, панельных швов и скрытых деталей остаются предметом 3D-сверки. Внешний вид задаёт основной утверждённый визуал, а не случайная деталь отдельной проекции.
