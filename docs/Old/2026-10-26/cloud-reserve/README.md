# Облако — поиск формы

Статус: перенесено в бэклог по решению автора. В активный ростер и производство не входит. Ни один вариант не утверждён. Листы созданы встроенным image_gen; [промпты](prompts.md).

## Работа юнита

Одна игровая единица из малых твёрдых летающих роботов. Подготовка атаки — 1,5 с: рой собирается в воронку. Затем поражает наземные цели в круге радиуса 2 на дальности до 3: до 12 урона/с каждой из максимум шести целей, вдвое меньше по тяжёлым и зданиям. При движении атака прекращается; следующая требует новой подготовки. Пассивного урона при пролёте нет. Источник правил — [DESIGN.md](../../../DESIGN.md).
