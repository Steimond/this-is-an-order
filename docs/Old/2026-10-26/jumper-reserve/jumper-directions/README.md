Варианты обычного контактного удара ещё предстоит уточнить, не вводить новые способности по виду кромок.

Сохраняются правила DESIGN.md: наземный боец ближнего боя с ограниченным прыжком через цель, не полёт и не обход стен/высот. Число ног не меняет характеристики. Эти варианты не заменяют утверждённые концепты Нода, паучка и игломёта.
