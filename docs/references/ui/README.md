# Референсы интерфейса

Сохранены 2026-10-21 как ориентиры стиля. Это сторонние изображения (готовые наборы HUD с маркетплейсов), лицензий на них нет: не нарезать и не использовать в игре. Интерфейс игры рисуется собственными векторными элементами — см. [UI.md](../../UI.md).

| Файл | Что берём |
| --- | --- |
| `hud-teal-orange-dashboard.webp` | Палитра командной темы меню: бирюзовый на почти чёрном и редкие оранжевые акценты; кольцевые индикаторы, тонкие гистограммы, рамки со скошенными углами. |
| `hud-modular-mono-facade.png` | Модульные плашки со срезанными углами, крупные цифры, пронумерованные блоки, монохромная иерархия. Основа для HUD экспедиционной фракции (сталь + янтарь). |
| `hud-hydra-coral.webp` | Коралловый на графите с кремовым текстом, сетки-миникарты с выносками, сегментированные шкалы. Основа для HUD фракции резонанса. |

Компоновка главного меню ориентируется на StarCraft II (верхняя панель, крупный персонаж в центре, контекст справа, главная кнопка внизу справа), но без копирования: навигация вынесена в левую колонку, центр занимает голосовой ассистент.
