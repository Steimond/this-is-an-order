# Проверка первого каркаса — 2026-10-21

Unity 6000.6.6f1, Entities 6.6.0. Это проверка основы приложения в редакторе; Windows Player, микрофон и производительность массового боя ещё не проверены.

## Автоматические проверки

В Unity Test Runner выбрать EditMode и сборку Order.Tests.EditMode. Через подключённый CLI:

```powershell
unity recompile --project-path C:/Projects/this-is-an-order/Game --json
unity command --project-path C:/Projects/this-is-an-order/Game test run --mode editor --filter Order.Tests.EditMode --filter_type assembly --async_tests true --json
unity command --project-path C:/Projects/this-is-an-order/Game test status --json
unity projects verify C:/Projects/this-is-an-order/Game --json
```

Результат: 20 тестов пройдено, 0 ошибок и 0 пропусков. Проверены составная команда громкости, границы и десятичные значения, отклонение неизвестных/неоднозначных команд, подготовка противника, сохранение образа ассистента, восстановление некорректных настроек, ошибка сохранения без частичного перехода, защита от устаревшего сеанса и ECS-идентификатор в отдельном World.

Итоговая компиляция: 0 ошибок, 0 предупреждений. Проверка целостности: отсутствующих/дублирующихся GUID, потерянных .meta и ошибок manifest не обнаружено.

## Проверка запущенной сцены

Сцена Assets/Order/Scenes/MainMenu.unity запущена в Play Mode. Проверено через инструменты редактора:

- Текстовая команда через обработчик кнопки меняет AudioListener.volume на 0.5 и открывает настройки звука.
- Синтетическое нажатие мышью на кнопку выполняет возврат в главное меню.
- Событие Enter, направленное во внутреннее поле текста, выполняет подготовку матча против второй фракции.
- UI отображается, текст читается, при нехватке высоты используется прокрутка. После проверки громкость восстановлена в 100%.

Снимки хранятся только во временной папке Game/Temp и не входят в репозиторий. Это техническая проверка взаимодействия, не тест удобства с участием игрока. Подготовка матча пока не создаёт боевой мир, ответ ассистента пока текстовый. Результаты распознавания речи и минимальные системные требования отсутствуют.
