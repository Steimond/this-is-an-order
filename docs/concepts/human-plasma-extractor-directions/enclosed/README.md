- A «Крытый цех»: Низкий крытый цех, прокачка по горизонтальной трубе на крыше.
- B «Кассета»: Компактный корпус в раме, вертикальный смотровой канал на фасаде.
- C «Двойной корпус»: Два цеховых объёма на сплошном основании, труба между ними.
- D «Барабанный цех»: Круглый закрытый завод, видимый трубопровод вдоль стенки.
- E «Ступенчатый завод»: Ступенчатый корпус с наклонным каналом прокачки.
- F «Периметр»: Низкий квадратный цех с технологическими блоками по углам и трубами по краям крыши.

Общее требование: сплошной корпус и основание полностью скрывают разлом, нет открытого колодца, просвета под заборником или добывающей головы вне здания. Плазма видна только внутри защищённых секций технологического трубопровода на крыше/фасаде. Песочные корпуса, графитовая сталь, оранжевые акценты и янтарные индикаторы сохраняют стиль людей.

Будущая анимация: движущаяся волна яркости внутри пурпурного объёма по пути из нижнего закрытого заборника в технологический блок. Скорость/ритм, режим простоя, насыщение рабочими и движение насосов пока не утверждены. Это статичные концепты, не готовая анимация.

Правила человеческого экстрактора сохраняются: установка на разломе с рабочими-дронами. Без рабочих активная прокачка не должна означать автоматическую добычу. Закрытие месторождения визуальное; не добавляет ресурс, броню, отдельную электросеть или невидимость. Перед моделированием сверить размеры с типовой геометрией разлома, точку взаимодействия и подход рабочих. 2×2 склада сюда автоматически не переносится.
