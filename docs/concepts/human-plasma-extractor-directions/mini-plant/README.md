# Экстрактор людей I «Мини-завод» — уточнение

2026-10-28. По просьбе автора: небольшой завод над разломом с видимой прокачкой пурпурной плазмы для будущей анимации. Вариант предложен, пока не утверждён.

[Основной концепт](hero.png) · [Просмотр](gallery.html) · [Первый проход A–H](../gallery.html).

Композиция: платформа над разломом, нижний заборник, вертикальная насосная колонна с защищённым смотровым участком, верхний горизонтальный трубопровод и закрытый машинный блок. Вода/плазма не хранится в огромном стеклянном баке: процесс читается по небольшим защищённым участкам.

Предложение анимации: фиолетовые импульсы поднимаются от разлома по колонне, проходят в горизонтальную трубу и исчезают в машинном блоке; яркость и скорость можно связать с текущей добычей. Без рабочих не показывать активную прокачку как доказательство автоматической добычи. Не закреплять буквальные отдельные цилиндрические «куски» из генерации как физический ресурс: для движения подойдёт непрерывная плазма с волной яркости. Конкретный эффект, скорость, число импульсов, режим простоя и работа насоса пока не утверждены и не реализованы.

Роль и правила не изменены: человеческий экстрактор на разломе с рабочими. Для окончательной геометрии проверить подход рабочих, размеры и единый непрерывный трубопровод. Художественный концепт не является размерным чертежом.

Происхождение: встроенный image_gen, один отдельный вызов, точный промпт hero.prompt.md. После утверждения — ракурсы, паспорт моделирования и запись в DESIGN.md.
