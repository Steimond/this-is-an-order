# Винтокрыл людей · A–H

Выбран E «Скоба» 30.10.2026. [Финальные референсы](modeling/gallery.html). Восемь вариантов сохранены как история. Роль: одиночная атака по земле, рейд против открытой пехоты; аэродром. Площадного урона, невидимости и транспортных функций нет. Конструкция винтов и оружия не утверждает новые способности, параметры или режим трансформации. Остановленные винты показаны для читаемости формы; лётная механика не проверена.

Создано 2026-10-30 встроенным imagegen. Полные промпты и пути исходников: [generation.json](generation.json).

- **A «Стриж»** — Компактный узкий корпус и два кольцевых подъёмных вентилятора. [Изображение](a.png), [промпт](a.prompt.md).
- **B «Ось»** — Соосные винты над гранёным корпусом, без длинной хвостовой балки. [Изображение](b.png), [промпт](b.prompt.md).
- **C «Конверт»** — Два крупных винта на концах короткого крыла и вытянутый тонкий фюзеляж. [Изображение](c.png), [промпт](c.prompt.md).
- **D «Стрела»** — Низкий вытянутый корпус, основной винт и кольцевой хвостовой винт. Задний толкающий пропеллер из запроса не получился. [Изображение](d.png), [промпт](d.prompt.md).
- **E «Скоба»** — Широкая поперечная рама с двумя винтами и короткая центральная кабина. [Изображение](e.png), [промпт](e.prompt.md).
- **F «Тандем»** — Два продольных винта, ступенчатый корпус и минимум выступающих крыльев. [Изображение](f.png), [промпт](f.prompt.md).
- **G «Клин»** — Один основной винт, закрытый хвостовой и выразительный клиновидный нос. [Изображение](g.png), [промпт](g.prompt.md).
- **H «Крест»** — Четыре компактных вентилятора в скошенной раме вокруг низкого корпуса. [Изображение](h.png), [промпт](h.prompt.md).

После выбора: единые нейтральные ракурсы → согласование объёма/осей винтов/оружия → UV и независимые зоны цвета игрока → риг, висение/движение/повороты/остановка/наведение/атака/смерть и переходы → Unity. Панели владельца должны читаться на корпусе и гондолах с игровой камеры при выключенных огнях; оранжевые детали концептов пока не являются готовой маской. Посадка и трансформация не добавлены как новые игровые режимы. Это изображения, не готовая 3D-модель.
