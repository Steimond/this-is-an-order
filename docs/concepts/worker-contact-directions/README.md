# Рабочий: A, B, F и ближняя атака

2026-10-26. [Шесть вариантов](01-variants.png) · [Промпт](prompt.md). Встроенный image_gen. Выбран A1, имя — «Нод». Золотистые электроды выдвигаются вперёд при атаке и дают короткий контактный разряд, затем убираются.

Верхний ряд A1/B1/F1 — контактные электроды в оболочке, ободе или центральной капсуле. Нижний A2/B2/F2 — короткие механические ударные накладки. Вставки поясняют контакт с тестовым блоком, не дальность атаки.

Ближняя атака подтверждена автором. Утверждена контактная электрическая атака: без автоматически добавленных оглушения, цепной молнии, урона по площади или дистанционного луча. Урон, период, цели и дальность требуют отдельного баланса. Накладки не дают отбрасывания автоматически. Добыча и стройка выполняются нанитной массой; руки и добывающие инструменты не возвращаются.

Геометрию контакта и устойчивость проверить после выбора. A2/B2 выглядят тяжелее и добавляют детали — альтернативы для сравнения, не утверждённые улучшения. Исходные варианты сохранены.
