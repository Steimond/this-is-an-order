# Резонанс · ракурсы выбранных зданий

28 октября 2026. [Галерея всех десяти типов](gallery.html). Семь новых листов дополняют уже выбранные Ядро A, Сборочный узел A и два режима Стража A+F.

Для каждого нового здания подготовлены: выбранный основной визуал, художественный лист FRONT/SIDE/REAR/TOP/3/4, контрольные проекции одной упрощённой сетки и OBJ. Промпты находятся рядом с изображениями. Новые листы развивают выбранную внешность и не выбирают новые варианты.

| Здание | Основные неизменные признаки |
| --- | --- |
| Вычислитель B5 | Три твёрдые вычислительные кассеты, две боковые щеки и общая верхняя перемычка. Без нанитных баков |
| Ретранслятор A | Две антенны разной высоты. Одна небольшая центральная камера. Асимметрия меняет сторону на заднем виде |
| Узел прошивки B | Один непрозрачный горизонтальный программирующий барабан и один считывающий блок над ним. Без жидкостных камер |
| Матрица E | Широкая прямоугольная платформа, куб/сфера/пирамида под общим навесом. Размер в клетках не назначен |
| Гнездо A2 | Ровно три одинаковых когтя на 120°, сходящихся вверх к центру. Не ангар или площадка выпуска |
| Глубинное ядро A | Квадратный углублённый проём, четыре угловых блока, внутренние нисходящие элементы. Не новый источник сети |
| Резервуар E | Одна наклонная основная ёмкость: передний конец ниже заднего. Не две производственные цистерны |

Геометрические каркасы фиксируют массу и взаимное расположение деталей. Они не являются точной реконструкцией каждой оболочки выбранных картинок. Размеры в blockout-specs.json условные, не метры и не игровые клетки. Каждая группа проекций строится из одной сетки; художественные изображения могут сохранять перспективные ошибки.

Перед детальным моделированием выбрать канонические поверхности по основному визуалу, затем построить одну общую модель и снять с неё окончательные проекции. Не создавать разные модели по каждому художественному ракурсу. Невидимые в основном визуале тыльные панели и служебные элементы считаются предложениями для детализации.

Этот пакет закрывает документальный набор основных видов и художественных ракурсов, но не означает готовность моделей, ригов, анимаций, эффектов, коллизий или баланса. Исходные выбранные формы не меняют роли зданий.

Скрипты: tools/docs/build-building-model-blockouts.cjs и tools/docs/build-building-model-gallery.cjs. Художественные листы созданы встроенным image_gen, по отдельному вызову на здание. Каркасы и OBJ созданы кодом.
