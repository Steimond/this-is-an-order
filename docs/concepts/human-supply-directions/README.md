# Склад снабжения людей — A–H

2026-10-28. Первый проход отклонён автором как слишком однообразный. Новое направление: минималистичный склад провизии, цистерна с водой и несколько ящиков. [Актуальные варианты A–H — второй проход](round-2/gallery.html). Ни один конкретный вариант пока не утверждён.

[Галерея](gallery.html) · [Выбранный штаб C](../human-hq-directions/c-closed.png) · [Игровые правила](../../DESIGN.md#humans).

Общий язык: песочная матовая наклонная броня, графитовые основания, приглушённые оранжевые панели и небольшие янтарные индикаторы. Все створки закрыты. Штаб использован только как референс материалов.

- A «Панцирь» — Цельный низкий бронекорпус с пологой крышей и центральной запирающей полосой.
- B «Кассеты» — Три закрытые грузовые кассеты на общем основании.
- C «Скоба» — Широкий складской блок между силовыми щеками под общей крышкой.
- D «Ступени» — Три ступенчатых объёма, повышающихся к задней части.
- E «Арка» — Гранёный свод и два наружных запирающих ребра.
- F «Коллектор» — Четыре складских блока вокруг низкого центрального соединения.
- G «Пакет» — Две кассеты одна над другой, стянутые силовыми лентами.
- H «Соты» — Три крупных гранёных люка в едином низком корпусе.

Роль: +10 лимита армии, без боевого усиления; предварительное пятно 2×2, 100 М, 22 с, 400 HP. Концепты не вводят производство, сдачу ресурсов, ремонт или новые способности. Изображения показаны крупно для сравнения архитектуры; реальный размер относительно штаба пока не зафиксирован. У B/E более вытянутые пропорции: при выборе проверить посадку в предварительное пятно, не менять игровой размер молча.

После выбора или правок автора: ракурсы для моделирования, фиксация выбранных признаков в DESIGN.md и пересборка PROJECT.html. Невидимые поверхности потребуют сверки на одном объёме.

Создано встроенным image_gen: восемь отдельных вызовов, один на вариант. Полные промпты a.prompt.md … h.prompt.md. Результаты a.png … h.png. Это поисковые концепты; мелкие потёртости и дробление панелей генерации не задают обязательные материалы финального ассета.
