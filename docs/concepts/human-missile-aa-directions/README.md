# Непушечная ПВО людей — ракетный поиск A–H

2026-10-28. Автор требует ПВО без пушек. Предложено восемь ракетных установок со строгими пропорциями. [Галерея](gallery.html) · [Точные промпты](generation.json). Выбран F «Барабан контейнеров» 2026-10-29. [Ракурсы и паспорт](modeling/gallery.html). Остальные варианты — история поиска.

- A «Спаренные кассеты»: Два длинных узких ракетных контейнера на общей люльке. Движение: Общий поворот и наклон кассет; крышки и эффект старта отдельно.
- B «Боковые блоки»: Два разнесённых двухконтейнерных блока по бокам центральной рамы. Движение: Поворот центральной рамы и общий наклон пусковых блоков.
- C «Односторонний щит»: Асимметричный щит и две наклонные ракетные кассеты. Движение: Щит поворачивается с установкой, кассеты наводятся по высоте.
- D «Ячеистый блок»: Закрытый наклонный блок из четырёх пусковых ячеек. Движение: Открытие крышки выбранной ячейки по событию пуска; корпус неподвижен.
- E «Веер»: Три узких контейнера с небольшим веерным разносом. Движение: Поворот общей рамы и наклон пускового блока.
- F «Барабан контейнеров»: Три ракетных контейнера вокруг индексируемого барабана. Движение: Пошаговый поворот барабана для выбора контейнера, наведение общей люльки.
- G «Продольная люлька»: Удлинённая пусковая люлька с двумя тонкими кассетами и подъёмными тягами. Движение: Поворот платформы, подъём люльки и работа связанных тяг.
- H «Защитная рама»: Две кассеты внутри лёгкой защитной рамы. Движение: Поворот и наклон рамы с контейнерами; эффект запуска отдельно.

Сохраняются параметры зенитной башни: 100 М / 25 П, 25 с, 500 HP, 2×2, мастерская, только воздух, исходные 18 урона/с и дальность 8. Выбор ракетного визуала не вводит конечный боезапас, залп по нескольким целям, ручную перезарядку, новый ресурс или способность. Наведение ракеты, частота/урон отдельного пуска, скорость полёта и обработка потери цели уточняются после выбора, без автоматического изменения общих правил летящих атак.

Восемь PNG нейтральные: контейнеры и люки закрыты, механизмы в покое, все лампы выключены. Оранжевый — краска. Нет огня, дыма, ракеты в полёте, вспышек и свечения. На AI-моделирование передавать нейтральные PNG; эффекты старта и их скриншоты не включать в базовый цвет.

У A/B/C/E/G/H разделить неподвижное основание, азимутальную платформу, люльку и контейнеры; контакты/тяги связывать с правильными осями. У F отдельный поворот барабана пошаговый, не пушечное вращение стволов; три контейнера не задают три выстрела до перезарядки. У D генерация дала наклонный ячеистый блок вместо запрошенного вертикального, он показан как фактический вариант; не утверждать вертикальный пуск по этой картинке. Способ раскрытия крышки выбранной ячейки — предложение, не финальный клип.

После выбора проверить единый объём, оси, зазоры, полный поворот и подъём кассет, вынос контейнеров и путь ракеты. Основание 2×2 не доказывает вписывание всех подвижных частей в это пятно. Скорость и угол наведения, количество/механика крышек, точное число ячеек и траектория пока не утверждены. Модели сохраняют сдержанные пропорции, не увеличивать толщину кассет/опор ради мультяшности.

После утверждения — нейтральные ракурсы, общий каркас/OBJ, паспорт движения/материалов, DESIGN.md и PROJECT.html. Затем стройка людей и разрушение обеих рас; шейдер/отдельные модели/сочетание остаются открытыми до отдельного этапа.

Происхождение: встроенный imagegen, восемь отдельных изображений a.png–h.png; точные промпты a.prompt.md–h.prompt.md сохранены рядом.
