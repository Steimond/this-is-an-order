Все листы показывают нейтральное симметричное положение, основной ракурс и дополнительные виды для выбора. Это ещё не окончательные модельные листы. После выбора сразу закрепить решение и сделать согласованные виды для моделирования.

Предложение визуала: один компактный электрический излучатель под носом с короткими парными электродами и направлением вперёд/вниз. Парные электроды относятся к одной точке выпуска разряда, не к двум независимым атакам. Подсветка и движители не являются дополнительным оружием. Конкретные двигатели, шарнир наведения и электроды утверждаются выбором/доводкой концепта; не добавляют форсаж, посадку, режим развёртывания или новые механики. Цепь разряда — отдельный эффект, не часть геометрии модели.

Создано встроенным image_gen. Материалы взяты из выбранного взломщика A; его колёса и антенна не переносятся. Проверить малые ракурсы и точки выхода разряда при подготовке выбранного модельного листа.

## Проверка проекций A
Автору подходит характер A, но виды крыла не согласованы. Эталон формы — большой исходный ракурс; нижний TOP исходного листа не использовать для моделирования. Первая правка отклонена автором и сохранена в Old/2026-10-26/glider-projection-drafts. [Отдельная попытка вида сверху](07-a-top-study.png) — исследование, не утверждённая проекция. Финальная геометрия и модельный лист ещё не согласованы. Генерация по одному ракурсу не доказывает точность; для гарантированного совпадения нужен единый 3D-блокинг и рендеры из него.
