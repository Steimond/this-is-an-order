# Гаубица людей · второй проход A–H

2026-10-29. Запрос автора: восемь более продвинутых и красивых вариантов. Все восемь новых изображений подготовлены встроенным imagegen, каждое отдельным запросом. [Галерея](gallery.html) · [Общий лист](overview.png) · [Точные промпты и происхождение](generation.json). Буквы нового прохода не совпадают с выбором или статусом старых A/C. **Выбран автором C «Стрела».** [Походное/развёрнутое состояния и паспорт](modeling/gallery.html). Остальные варианты — история.

| Вариант | Отличие |
| --- | --- |
| A «Монолит» | Высокая узкая казённая стойка, светлые скошенные боковые щиты, низкий корпус. |
| B «Камертон» | Открытая раздвоенная силовая рама вокруг одного орудия, длинные гусеничные борта. |
| C «Стрела» | Вытянутый гранёный кожух, стреловидная люлька и клиновидный нос. |
| D «Мост» | Разнесённые борта и широкая поперечная рама, открытая середина. |
| E «Корона» | Сегменты защитных плит вокруг люльки, компактная база. |
| F «Обелиск» | Тёмная вертикальная стойка над светлым низким корпусом, строгие плоскости. |
| G «Каскад» | Ступенчатые кожухи и наклонная открытая люлька. |
| H «Атлас» | Массивная открытая силовая рама, крупные боковые шарниры и опоры. |

Песочные, графитовые и светлые крупные группы материалов различаются по расположению; оранжевые акценты малы, потёртости локальны. У A/F близок вертикальный силуэт; отличаются броневые щиты и раскладка тёмных/светлых масс. B/H относятся к открытым рамам, но у B высокие пронги, у H массивные нижние треугольные связи. Это полезные пары для сравнения, не восемь гарантированно независимых конструкций.

Все изображения показывают только развёрнутое состояние. Одна пушка, две гусеницы, неподвижные наземные опоры и отделённая верхняя группа. Количество/форма опор, шасси, пропорции, цвета и подвижные узлы остаются предложениями. На рисунках некоторые погоны смещены относительно центра корпуса; это не утверждённое расположение и требует проверки вместе с выбранным силуэтом.

**Обязательное решение автора сохраняется: наведение и стрельба на 360° в развёрнутом состоянии.** Погон и низкая палуба учитывают возможность вращения, но один вид не доказывает полный круг, допустимое возвышение и зазоры при отдаче. После выбора подготовить походное состояние, поворот вбок/назад и обратное складывание, затем свести всё на одной геометрии. Не считать декоративные стойки и треугольные связи готовой кинематикой; проверить, что вращаемая группа не привязана к неподвижному корпусу/опорам.

Правила боя, развёртывания и исследований не меняются: [паспорт механики первого прохода](../README.md), [DESIGN.md](../../../DESIGN.md#rules), [производственные правила](../../../BLENDER_ASSET_RULES.md). Числа и типы оружия не назначаются внешним видом. Приводы, маски владельца, эмиссия, риг, полный набор анимаций, LOD, экспорт и Unity-проверка ещё не выполнены. Эти листы — варианты для обсуждения, не готовые 3D-ассеты.
