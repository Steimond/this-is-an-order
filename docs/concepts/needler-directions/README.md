- B: низкая широкая платформа, спаренные направленные вперёд орудия.
- C: высокая стойка, единая трёхканальная кассета.

Цель: брутальность через массу и конструкцию, читаемые оружие и направление атаки, минимум мелких деталей. Четыре ноги — варианты для игломёта, не требование ко всем юнитам. Трёхногие ходящие машины не продолжаем. Иглы должны считываться как физические снаряды; небольшие светящиеся элементы на картинке не задают энергетическое оружие. A и D близки; при развитии D асимметрию стоит усилить. Это поиск формы, не новые характеристики, дальность или тип атаки.

Игломёт C утверждён; далее по одному пересматриваем остальных. У паучка ноги должны читаться как оружие ближнего боя. Взломщику нужен понятный функциональный образ. HUD и люди сохраняют своё направление.


Базовая атака: одна игла из каждого из трёх стволов по очереди, с равными интервалами, повтор 1 → 2 → 3 → 1. Автор предложил исследование быстрых очередей для повышения среднего DPS. Рабочий вариант: три быстрых последовательных выстрела, затем пауза; числа и размещение исследования ещё не утверждены. Новая картинка для завершения этого концепта не требуется.
