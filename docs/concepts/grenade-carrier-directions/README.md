## Игровая основа

Источник правил — [DESIGN.md](../../DESIGN.md#backlog). Старт с одной готовой гранатой, вместимость до трёх. Каждая новая требует ресурсов и времени. Можно не пополнять запас, заказать вручную или включить автопополнение до максимума. Боеприпас скользит к цели по земле с исчезающим нанитным следом, взрыв — сферический разлёт игл. Уничтожить или перехватить гранату нельзя, избежать урона можно выходом из области взрыва.

Наземная огневая поддержка против плотных групп — предлагаемая роль. Характеристики, цена боеприпаса, момент фиксации области взрыва и детали наведения ещё не утверждены.
