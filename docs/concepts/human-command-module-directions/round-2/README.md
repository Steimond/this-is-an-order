# Командный модуль — самостоятельное здание, второй проход

2026-10-28. Автор отменил пристройку: статичные здания могут заблокировать стыковочное место. Требуется больше 2×2 и крупная верхняя механика. Рабочее предложение — 3×3, окончательный размер после выбора. [Галерея](gallery.html) · [Точные промпты](generation.json).

- A «Орбитальная рама»: Большое наклонное кольцо на двух опорах над низким корпусом. Движение: Поворот кольца между боковыми опорами; точную ось и диапазон согласовать с подшипниками на общей геометрии.
- B «Поперечный барабан»: Крупный поперечный барабан между двумя встроенными опорами. Движение: Барабан вращается вокруг горизонтальной оси; опоры неподвижны.
- C «Синхронные каретки»: Две крупные каретки на раздельных продольных направляющих. Движение: Встречный ход кареток вперёд-назад в отдельных полосах.
- D «Поворотная кассета»: Крупная вертикальная аппаратная кассета на круглом погоне. Движение: Поворот кассеты вокруг вертикальной оси.
- E «Качающаяся скоба»: Массивная скоба над закрытым корпусом, закреплённая на боковых шарнирах. Движение: Скоба качается вперёд-назад на ограниченный угол.
- F «Роторные диски»: Два широких диска на независимых опорах над гранёным корпусом. Движение: Диски вращаются в противоположных направлениях.
- G «Подъёмный блок»: Большой аппаратный блок над крышей на четырёх направляющих. Движение: Короткий вертикальный ход блока вверх-вниз.
- H «Диагональный ход»: Массивный диагональный мост с одной крупной аппаратной кареткой. Движение: Каретка проходит вдоль диагонали крыши и возвращается.

Роль остаётся технологической: доступ к третьему уровню, требует завод или аэродром. Строится рабочим в свободном месте без связи со штабом, не использует его очередь. 150 М / 150 П, 55 с и 350 HP пока сохранены; новый размер и заметная механика сами по себе не меняют боевые числа. Своей очереди производства/исследований у модуля нет. Точная привязка цикла и режимы ожидания/готовности уточняются после выбора, новые способности не добавлены.

Все PNG a.png–h.png нейтральные: механизмы в покое, свет выключен, линзы тёмные, оранжевый — краска. Не запекать свечение в albedo. Для AI-моделирования передавать PNG, не скриншоты активных схем. Модельные ракурсы и геометрия будут после выбора.

Схемы условные. Для A картинка дала опоры по диаметру кольца: нельзя автоматически вращать его вокруг нормали на таких подшипниках. До моделирования согласовать одну реальную ось, крепления и безопасный диапазон; показано только направление поиска. Для B торцевые подшипники неподвижны, вращается барабан. Для C отдельные полосы и ограничители не дают кареткам пересекаться. Для D проверить полный поворот кассеты над боковыми блоками. Для E ограничить качание до безопасного угла. Для F проверить расстояния дисков до перегородки. Для G корпус под блоком остаётся закрытым, хода хватает над кровлей. Для H уточнить диагональную трассу, конечные упоры и зазор.

Проверить все крайние положения и полный поворот на единой геометрии в пятне 3×3. Художественные изображения не доказывают кинематические зазоры и не являются размерными чертежами. Отделить механизм от неподвижных опор и корпуса, сохранить оранжевые метки для читаемости вращения. Точный темп, easing и синхронизация ещё не утверждены.

Происхождение: встроенный imagegen, восемь отдельных вызовов; PNG и точные a.prompt.md–h.prompt.md сохранены рядом. Отдельные схемы — SVG/CSS. Выбран A с уточнённой механикой: [ракурсы и паспорт](modeling/gallery.html). Варианты выше сохранены как история; окончательная обойма/ротор и оси заданы в modeling/.
