## Новая функция
Дальний боевой юнит выпускает 3–4 капсулы; они летят и падают на землю, выпускают маленькие шарики-гранаты. Шарики подъезжают вплотную и взрываются с очень малым радиусом. Исследование открывает режим лечебных шариков, которые расходуются рядом со своими юнитами, восстанавливая HP. Числа, производство, наведение и уязвимость шариков пока открыты. Старое сервисное поле отменено; правила гранат «Шлюза» автоматически не наследуются.
