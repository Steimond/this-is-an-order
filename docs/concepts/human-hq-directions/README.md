## Происхождение и ограничения

Встроенный image_gen: восемь отдельных вызовов, один концепт на вызов. Точные промпты — a.prompt.md … h.prompt.md; картинки — a.png … h.png. Художественные поисковые ракурсы, не готовые размерные чертежи. Стыки, мелкий износ, высоты антенн и внутренние детали уточняются после выбора; ворота не фиксируют новые правила сдачи ресурсов. Окраска фракции требует отдельной читаемой маркировки стороны в игре.
