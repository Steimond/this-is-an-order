Один порядок для каждого юнита: основной визуал → художественные виды → раскрытая форма → контроль геометрии и OBJ. Упрощённые контрольные проекции получены из одной сетки и согласованы между собой. Художественные генерации уточняют материалы и оболочки, но ещё могут расходиться в деталях и перспективе. Для окончательных детальных ракурсов нужен рендер одной модели. Сохраняемые надписи STYLE EXPERIMENT на исходных визуалах относятся к их происхождению.
