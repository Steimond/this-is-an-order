# D «Серп» · острые законцовки

Законцовки по правке автора: зеркальные острые гранёные серпы к кабине, с ломаным контуром вместо плавных скруглений. Сохранены одна центральная подъёмная турбина и одно заднее сопло с поворотом вниз. Ракеты на подвесах остаются предложением.

Встроенный imagegen, полные промпты/источники в generation.json и *.prompt.md. Прежние версии сохранены отдельно. Изображения для оценки внешности, не готовая модель: геометрию, симметрию/масштаб, поворот сопла и зазоры проверить на общей сетке. UV/зоны владельца, риг, анимации, LOD и Unity ещё не готовы.


Финализирован D «Серп» 31.10.2026. Актуальный модельный пакет: ../modeling/gallery.html.
