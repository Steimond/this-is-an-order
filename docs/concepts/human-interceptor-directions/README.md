# Перехватчик людей · A–H

Восемь вариантов внешности, выбор ещё не сделан. Роль: воздушный контроль, атака только по воздуху; аэродром. Сохраняется исследуемый форсаж: +25% скорости на 4 с, откат 25 с, без иммунитета. Вид оружия и число двигателей не утверждают новый баланс, тип снаряда или режимы. Нет превращения в наземного бойца. Это художественный поиск, не проверенная аэродинамика.

Создано 2026-10-30 встроенным imagegen. Полные промпты и пути исходников: [generation.json](generation.json).

- **A «Игла»** — Узкий длинный нос, стреловидное крыло и два разнесённых двигателя. [Изображение](a.png), [промпт](a.prompt.md).
- **B «Дельта»** — Широкое треугольное крыло и короткий утопленный корпус. [Изображение](b.png), [промпт](b.prompt.md).
- **C «Канард»** — Передние канарды, узкая талия и гранёные боковые воздухозаборники. [Изображение](c.png), [промпт](c.prompt.md).
- **D «Серп»** — Обратная стреловидность и компактные задние двигатели. [Изображение](d.png), [промпт](d.prompt.md).
- **E «Вилка»** — Две продольные балки с двигателями и центральная кабина. [Изображение](e.png), [промпт](e.prompt.md).
- **F «Ромб»** — Ромбовидный план крыла и гладкий низкий профиль. [Изображение](f.png), [промпт](f.prompt.md).
- **G «Ступень»** — Короткое ступенчатое крыло и высокие задние гондолы. [Изображение](g.png), [промпт](g.prompt.md).
- **H «Стрела»** — Длинный центральный корпус, малая площадь крыла и один крупный двигатель. [Изображение](h.png), [промпт](h.prompt.md).

После выбора: единые нейтральные ракурсы → согласование объёма/двигателей/оружия → UV и независимые зоны цвета игрока → риг, полёт/повороты/остановка по правилам игры/наведение/атака/форсаж/выход из форсажа/смерть и переходы → Unity. Панели владельца должны читаться на корпусе и гондолах с игровой камеры при выключенных огнях; оранжевые детали концептов пока не являются готовой маской. Посадка и трансформация не добавлены как новые игровые режимы. Это изображения, не готовая 3D-модель.
