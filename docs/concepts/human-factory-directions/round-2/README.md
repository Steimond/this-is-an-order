# Завод людей — второй проход A–H

2026-10-28. Первый проход оказался слишком однообразным. Здесь изменена архитектура самого корпуса, а не только оборудование крыши. Выбран D «Вертикальная сборка» 2026-10-28. [Ракурсы и паспорт моделирования](modeling/gallery.html).

[Галерея](gallery.html) · [Первый проход](../gallery.html) · [Промпты и происхождение](generation.json) · [Рабочие циклы](work-cycles.json)

- A «Веер»: Три крупных складки крыши расходятся веером к широкому фасаду. Рабочий цикл: Волна света вдоль тёмных полос на складках крыши.
- B «Седло»: Крыша провисает седлом между поднятыми краями; массивные боковые опоры. Рабочий цикл: Короткий подъём и возврат одной вентиляционной створки в седловине.
- C «Три пролёта»: Три закрытых производственных крыла сходятся в центральном зале. Рабочий цикл: Три группы линз поочерёдно показывают работу крыльев.
- D «Вертикальная сборка»: Низкий выпускной зал и высокая сборочная шахта с наружной кареткой. Рабочий цикл: Оранжевая каретка совершает короткий вертикальный ход по направляющим.
- E «Оболочка»: Асимметричная оболочка: высокое левое плечо и низкий правый край. Рабочий цикл: Последовательность световых ячеек на высоком плече оболочки.
- F «Диагональный хребет»: Два смещённых цеха связаны толстым диагональным техническим хребтом. Рабочий цикл: Бегущая волна по диагностической полосе диагонального хребта.
- G «Спиральный цех»: Секции самого корпуса поднимаются по спирали к центральному ядру. Рабочий цикл: Три группы линз загораются по кругу. Сам корпус неподвижен.
- H «Сдвинутые кассеты»: Четыре сцепленных объёма разной высоты, задняя консоль на диагональной опоре. Рабочий цикл: Короткий горизонтальный ход технической плиты над воротами.

Назначение и баланс сохраняются: 175 М / 75 П, 45 с, 1000 HP, 3×3; требует оперативный центр. Танк, гаубица при командном модуле, зенитчик, модификации техники. Одна очередь для производства и исследования. Эффекты следуют фактическому прогрессу, не вводят дополнительных способностей и задержек выхода.

Нейтральные PNG a.png–h.png: лампы выключены, механизмы в покое, ворота закрыты. Оранжевый — краска; никаких свечения, искр и запечённой эмиссии. Для AI-моделирования передавать отдельный нейтральный PNG, без скриншотов схем. Рабочие эффекты и маски отдельно от albedo.

Схемы SVG/CSS условные: не задают точные размеры, число линз, оси и амплитуды. Для B выбранная решётка требует подвижного верхнего элемента над закрытым техническим объёмом. Для D отдельно выделить каретку и направляющие. Для H движется только встроенная плита, не консоль здания. Перед моделированием выбранного варианта проверить габарит 3×3, высоты, масштаб ворот и путь техники по общей геометрии; концепты не являются размерными чертежами.

После выбора — нейтральные ракурсы, единая геометрия, паспорт частей и анимации, запись в DESIGN.md и пересборка PROJECT.html.

Происхождение: встроенный imagegen, восемь отдельных вызовов. Изображения и точные промпты сохранены рядом: a.png–h.png и a.prompt.md–h.prompt.md.
