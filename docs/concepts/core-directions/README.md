## Функции

Источник правил — [DESIGN.md](../../DESIGN.md), раздел 03. Производит Нодов по одному; готовое здание даёт 20 лимита, самостоятельное покрытие радиуса 10 и квоту трёх сборочных узлов. Можно строить вне сети, покрытие появляется после завершения. Боевые юниты производятся сборочным узлом, не Ядром. Строительство расходует Нода.

Текущие предварительные числа: списание 350 М, полная цена с Нодом 400 М; 65 с, 1500 HP, 4×4. Внешность не меняет эти числа, проходимость и правила сети.

- [A — Цитадель](01-a.png): Ступенчатая центральная башня на широком основании.
- [B — Кольцо](02-b.png): Массивное замкнутое кольцо вокруг невысокого центра.

- [D — Бастион](04-d.png): Низкая крепостная форма с поднятой задней частью.
- [E — Опора](05-e.png): Центральный блок под крышкой на четырёх архитектурных опорах.
- [F — Каскад](06-f.png): Широкий корпус с вложенными ступенчатыми террасами.

Цель: узнаваемый центр базы с игровой камеры. Твёрдый машинный корпус, несколько крупных масс, основание без ворот и пандусов, широкие поверхности для цвета владельца. Материал нанитный, но готовое здание не выглядит жидкой сущностью. Вид сверху — эскиз силуэта, не точный чертёж. После выбора потребуются модельные виды, проверка масштаба с Нодом, коллизий, внешней сборки Нода из нанитной массы и состояния строительства. Названия вариантов — названия архитектурных направлений, не переименование здания. Не путать с Глубинным ядром — отдельным технологическим зданием.
