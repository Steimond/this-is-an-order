## Статусы
Новые A–F — предложения для выбора. Названия направлений не переименовывают здания. Правила, стоимость, роли и производство не меняются. Ядро A «Сердце», Сборочный узел A «Цистерны» и Страж A+F сохраняют выбранные формы. Четыре исправленных исследования для этих зданий доступны отдельно и не утверждаются автоматически.
Гнездо — исследовательская технология авиации, без производства, ангара и полосы. Глубинное ядро — технология III, не штаб и не источник сети. Резервуар не копирует две длинные параллельные цистерны Сборочного узла.
## Происхождение
Все изображения — встроенный image_gen, один отдельный вызов на один вариант или исправленный лист. Без CLI/API. Материальные референсы — выбранные Ядро A и Сборочный узел A, только для стиля. Силуэты A–F описаны отдельно для каждого здания.
Точные промпты сохранены рядом с каждым PNG в *.prompt.md. Реестр — manifest.json; результаты выполнения — generation-status.json. Замечания к картинкам — review-notes.json и AUDIT.md. В галерее можно локально отметить несколько кандидатов; отметка не изменяет DESIGN.md.
## Границы
Это художественные поисковые ракурсы, не размерные чертежи или готовые модели. Размер между картинками условен. Прозрачная нанитная масса не вводит новый ресурс, отдельную уязвимость или обязательную дорогую симуляцию жидкости. Сохранившиеся мелкие поверхностные линии/износ генерации не являются целевым материалом: финальное покрытие свежее и чистое.
После выбора: закрепить вариант, подготовить один общий объёмный блок, затем согласованные ракурсы и паспорт частей. Не моделировать конфликтующие проекции как разные объекты.
