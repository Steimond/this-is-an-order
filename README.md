# this-is-an-order

Голосовая RTS на Unity: экономика, строительство баз и сражения с сотнями юнитов. Сначала — игра против бота, затем PvP 1 на 1; цель — выпуск в Steam с двумя расами.

Unity-проект находится в `Game/`: Unity `6000.6.6f1`, шаблон `3D URP` (`com.unity.template.urp-blank`), URP `17.6.0`. Открывать в Unity Hub нужно эту подпапку. Кэш и локальные настройки исключены из Git; папки Assets, Packages и ProjectSettings сохраняются вместе с .meta-файлами.

Создан каркас приложения с отдельными сборками и Entities 6.6.0. Предложения сеттинга и рас в концепции требуют согласования.

## Первый прототип меню

Перед первым запуском выполните `./tools/Prepare-LocalAI.ps1` из корня репозитория: скрипт скачает локальную модель и runtime с проверкой SHA-256. На этой машине загрузка уже выполнена. Затем откройте `Game/Assets/Order/Scenes/MainMenu.unity` и нажмите Play. Главное меню оформлено в футуристическом стиле: навигация слева, анимированный ассистент с консолью приказов в центре, контекстная панель справа, окно настроек с вкладками (часть параметров — заглушки), собственный курсор и звуки интерфейса. Доступны выбор временного образа ассистента, общая громкость и подготовка матча против бота; громкость и образ сохраняются локально. Устройство и ограничения — в [UI.md](docs/UI.md). Матч пока не запускается, микрофон и озвучивание ещё не подключены.

Кнопки и текстовые команды используют один маршрут проверки: каждым элементом меню можно управлять командой в консоли ассистента (кнопка «Отправить» или Enter). Явные команды меню разбираются без нейромодели, список — по команде «помощь» и в [UI.md](docs/UI.md#команды-ассистента). Примеры:

- `Открой графику`, `Тени высокие`, `Включи вертикальную синхронизацию`
- `Назначь разговор на B`, `Противник вторая фракция`, `Полигон`, `Назад`, `Выход`
- `Перейди в настройки звука и убавь общую громкость до 50%`
- `Установи громкость до 100%`
- `Запускай матч против бота второй фракции`
- `Вернись в главное меню`
- `Громкость 11 процентов`
- `Сделай потише`

Работает локальная модель Qwen2.5 1.5B вместе с быстрыми опорными правилами и проверкой чисел/контекста. Можно варьировать формулировки в пределах реализованных функций меню; экспериментальный разборщик ещё может ошибаться. Неоднозначные фразы дают уточнение; ответ следует повторить полной командой. «Запускай матч» сейчас открывает подготовку и явно сообщает, что боевой прототип ещё не реализован. Названия «Фракция 1/2» временные. Устройство, загрузка и ограничения описаны в LOCAL_AI.md.

EditMode-тесты находятся в сборке `Order.Tests.EditMode` и запускаются через Unity Test Runner. Технические инструменты: меню редактора `Order/Create Main Menu Scene` создаёт стартовую сцену, если её ещё нет. Первая платформа — Windows x64; минимальные требования ещё не измерены.

## Тестовая RTS-карта

Откройте `Game/Assets/Order/Scenes/TempleBasin.unity` и нажмите Play либо выберите «Тестовая карта · Temple Basin» в главном меню. Доступны возвышенные старты и рампы, рабочий и тестовый отряд (штурмовики, стрелки, винтокрыл), движение юнитов, строительная сетка, два временных ресурса с упрощённой добычей, клеточный туман войны, миникарта и HUD. Управление и ограничения: [TEST_MAP.md](docs/TEST_MAP.md). Это полигон без бота и боя.

## Подключение редактора

В проект установлен `com.unity.pipeline` версии `0.9.0-exp.1` для Unity CLI и MCP. Откройте `Game/` в Unity и дождитесь окончания компиляции. Проверка: `unity status --json`; запрос к проекту: `unity command --project-path C:/Projects/this-is-an-order/Game editor status --json`.

MCP запускается командой `unity mcp --project-path C:/Projects/this-is-an-order/Game`. В локальной конфигурации Codex сервер `unity_mcp` привязан к этому проекту. После изменения конфигурации может потребоваться перезапуск Codex для загрузки инструментов в чат. На другой машине нужно настроить собственный путь к CLI и проекту.
