# this-is-an-order

Голосовая RTS на Unity: экономика, строительство баз и сражения с сотнями юнитов. Сначала — игра против бота, затем PvP 1 на 1; цель — выпуск в Steam с двумя расами.

## Документы проекта

- [План разработки](docs/ROADMAP.md) — этапы и условия перехода.
- [Концепция игры](docs/CONCEPT.md) — рабочее предложение сеттинга и границы первой версии.
- [Текущие задачи](docs/BACKLOG.md) — ближайшие шаги и критерии проверки.
- [Принятые решения](docs/DECISIONS.md) — договорённости и открытые вопросы.

Сейчас завершена подготовка документов для обсуждения концепции и архитектуры. Unity-проект и игровые прототипы ещё не созданы. Предложения в концепции требуют согласования.
